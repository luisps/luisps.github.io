# Luís Paulo Santos — Personal Website

This is a Jekyll site configured for **GitHub Pages** using the **Minimal Mistakes** theme.

## Deploy on GitHub Pages

1. Create a repository and push this folder contents to the repo root.
2. GitHub → **Settings → Pages**
3. Source: **Deploy from a branch**
4. Branch: your default branch, Folder: `/(root)`

## Local preview (optional)

```bash
bundle install
bundle exec jekyll serve
```
